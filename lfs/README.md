# LFS Toolkit

This directory provides convenient entry points for Git LFS workflows used in this repo.

Contents:
- `setup_lfs.sh` — wrapper to scripts/setup_lfs.sh
- `install_precommit_hook.sh` — wrapper to scripts/install_precommit_hook.sh
- `precommit_size_guard.sh` — wrapper to scripts/precommit_size_guard.sh

See also:
- `../scripts/history_cleanup.md` for optional full history rewrite guidance
- `../WORKFLOW_DATA_LFS.md` for end-to-end usage guide
